# 03 · 数据库设计

> 版本：v1.0　|　日期：2026-10-21　|　建表脚本见 `sql/init.sql`
> 字符集统一 `utf8mb4`；敏感字段只存脱敏值或密文。

## 1. ER 关系概览

```
sys_user ─┬─ sys_user_role ── sys_role ── sys_role_permission ── sys_permission
          │
biz_enterprise_info（企业资质）
biz_contact（联系人，敏感字段脱敏）
biz_ledger_category ── biz_ledger_field（自定义分类与字段）

三大台账：
biz_finance_ledger（财务流水）   —— 跨台账关联 —— biz_customer_ledger（客户）
biz_inventory_ledger（库存明细） —— 跨台账关联 —— biz_customer_ledger

支撑表：
sys_backup_log（备份记录）   sys_alert_rule（预警规则）   sys_alert（预警记录）
sys_update_log（更新日志）   biz_knowledge_doc（知识库文档）
```

**关系说明**：
- `sys_user` 与 `sys_role` 多对多（`sys_user_role`）
- `sys_role` 与 `sys_permission` 多对多（`sys_role_permission`）
- 客户台账关联财务流水：客户「累计合作金额/应收账款」由财务流水聚合计算（非冗余主数据，可定时回写）
- 客户台账关联库存：客户常采购商品通过库存台账的供应商/采购记录标记优先级

## 2. 数据字典

### 2.1 权限控制

**sys_user（系统用户）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, 自增 | 主键 |
| username | VARCHAR(64) | UNIQUE | 登录名 |
| password | VARCHAR(255) | NOT NULL | 密码(加密) |
| real_name | VARCHAR(64) | | 姓名 |
| phone | VARCHAR(16) | | 手机号(脱敏显示) |
| email | VARCHAR(128) | | 邮箱(脱敏显示) |
| status | TINYINT | 默认1 | 1正常 0锁定 |
| fail_count | INT | 默认0 | 连续失败次数(≥3锁定) |
| created_at / updated_at | DATETIME | | 时间戳 |

**sys_role（角色）**：`id, role_code(UNIQUE), role_name, description`
默认数据：`OWNER 企业负责人 / FINANCE 财务负责人 / KEEPER 库管 / EMPLOYEE 普通员工`

**sys_user_role（用户-角色）**：`user_id, role_id` 复合主键

**sys_permission（权限点）**：`id, module, operation, name`，`(module,operation)` 唯一

**sys_role_permission（角色-权限）**：`role_id, permission_id` 复合主键

### 2.4 自定义扩展

**biz_ledger_category（台账分类）**：`id, name(UNIQUE), is_preset, description, created_at`
默认数据：财务流水台账 / 库存明细台账 / 客户信息台账（is_preset=1）

**biz_ledger_field（自定义字段）**：`id, category_id, field_key, field_name, field_type, required`

### 2.5 支撑表

**sys_backup_log（备份记录）**：`id, backup_type(auto/manual), storage(local/oss/dual), file_path, status(success/failed), retry_count, error_msg, backup_time`

**sys_alert_rule（预警规则）**：`id, rule_name, rule_type, target, threshold, notify_way(消息/短信/邮件), enabled`

**sys_alert（预警记录）**：`id, rule_id, alert_type, target, current_val, status(UNRESOLVED/RESOLVED), remind_time, created_at, resolved_at`

**sys_update_log（更新日志）**：`id, biz_type, biz_id, operator, reason, created_at`

**biz_knowledge_doc（知识库文档）**：`id, title, file_path, status(PENDING/PARSED/FAILED), created_by, created_at`

## 3. 设计要点

1. **脱敏展示**：手机号/邮箱原文存储，出参层统一脱敏；仅授权角色可见原始值；禁止存储身份证号/银行卡号，符合个保法要求
2. **台账可扩展**：自定义分类 + 自定义字段（`biz_ledger_category`/`biz_ledger_field`）支撑业务扩展，无需改表
3. **审计可追溯**：`sys_update_log`(更新日志)、`sys_backup_log`(备份记录)、操作日志满足审计要求
4. **预警独立**：规则表(`sys_alert_rule`)与记录表(`sys_alert`)分离，规则可配置、记录可跟踪
5. **金额精度**：统一 `DECIMAL(18,2)`，避免浮点误差
