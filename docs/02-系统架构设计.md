# 02 · 系统架构设计

> 版本：v1.0　|　日期：2026-10-21

## 1. 总体架构

采用**前后端分离**架构，前端 SPA + 后端 RESTful API，横向分层、纵向按模块切分。

```
┌─────────────────────────────────────────────────────────────┐
│                        前端 (Vue3 SPA)                        │
│  登录/工作台/企业信息/台账管理/智能报表/权限/备份/预警/AI助手     │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP (JSON) / axios + /api 代理
┌──────────────────────────────▼──────────────────────────────┐
│                      后端 (Spring Boot)                       │
│  ┌────────────┐  ┌────────────┐  ┌───────────────────────┐  │
│  │ Controller │→ │  Service   │→ │  Repository (JPA)     │  │
│  │  接口层    │  │  业务逻辑层 │  │  数据访问层            │  │
│  └────────────┘  └────────────┘  └───────────────────────┘  │
│        统一返回/全局异常 · 安全过滤链 · 参数校验                │
└──────────────┬───────────────────────────────┬───────────────┘
               │ JPA/Hibernate                 │ HTTP
        ┌──────▼──────┐                  ┌──────▼──────┐
        │  MySQL 8    │                  │ 外部服务     │
        │  业务库      │                  │ LLM API     │
        └─────────────┘                  │ 向量库      │
                                          │ 阿里云 OSS  │
                                          └─────────────┘
```

## 2. 技术选型

| 层 | 技术 | 选型理由 |
|----|------|----------|
| 前端框架 | Vue 3 + Vite | 轻量、上手快、H5 适配友好 |
| UI 组件 | Element Plus | 企业级组件齐全，加速表单/表格/图表开发 |
| 状态/路由 | Pinia / Vue Router | 官方配套 |
| 图表 | ECharts | 折线/饼图/柱状图原生支持 |
| 后端框架 | Spring Boot 3.3 | 稳定、生态成熟、并发与事务支持好 |
| 数据访问 | Spring Data JPA | 快速 CRUD，配合原生 SQL 优化复杂报表 |
| 数据库 | MySQL 8 | 需求指定，稳定 |
| 安全 | Spring Security + JWT | 分级角色 + 细粒度权限 |
| 接口文档 | SpringDoc OpenAPI | 自动生成 Swagger |
| AI | LLM API + 轻量向量库 | RAG 财税知识库 |
| 备份存储 | 本地 + 阿里云 OSS(可选) | 双存储防单点 |

## 3. 后端分层与模块划分

```
com.sme.ledger
├── common/       统一返回(ApiResult)、业务异常、全局异常处理
├── config/       跨域(CORS)、安全(Security)、缓存/定时任务
├── controller/   各模块 RESTful 接口
├── service/      业务逻辑（校验、关联更新、报表聚合、预警判断）
├── repository/   JPA 数据访问接口
├── entity/       实体（与数据库表映射）
├── dto/          入参/出参对象（脱敏字段在出参层处理）
└── module/       后续可按模块分包（enterprise/ledger/report/auth/backup/alert/rag）
```

**核心模块依赖关系**：

```
企业基础信息 ←─────── 权限控制（所有操作先鉴权）
台账分类管理 ←─────── 数据录入与校验
智能报表 ──────────── 读取三大台账聚合
异常预警 ──────────── 监听库存阈值 / 资质到期
数据备份与恢复 ──────── 全量数据
财税RAG助手 ─────────── 读取台账统计摘要 + 向量知识库
```

## 4. 前后端交互逻辑

### 4.1 统一约定

- 所有接口返回统一结构 `ApiResult{code, message, data}`，`code=200` 成功
- 前端 axios 统一拦截：`code≠200` 弹出 `message`；网络异常统一提示
- 请求头：登录后 `Authorization: Bearer <JWT>`
- 开发环境 Vite 将 `/api` 代理到后端 8080，规避跨域

### 4.2 关键交互流程

**登录鉴权**
```
用户输入账号密码 → 后端校验 → 连续失败≥3次锁定账号
  → 成功签发 JWT → 前端存储 → 后续请求携带 → 后端过滤器校验角色/权限
```

**数据录入 + 校验**
```
表单提交 → 前端格式校验(金额/手机号标红)
  → 后端参数校验(@Valid) → 业务重复校验(凭证号+金额+日期)
  → 通过则入库 → 返回结果 / 失败则弹窗提示
```

**库存预警触发**
```
库存入库/出库/阈值调整 → 比较 库存数量 < 最低阈值
  → 生成预警记录 → 按用户通知方式推送(消息/短信/邮件)
  → 未处理则重复提醒直至「已解决」
```

**报表生成**
```
选择报表类型 + 筛选(时间/类别) → 后端聚合 SQL 统计
  → 返回数据 → 前端 ECharts 渲染(折线/饼图/柱状图) → 可导出 Excel/PDF
```

**备份与恢复**
```
定时任务(Quartz)触发全量备份 → 本地/OSS 存储 → 记录结果
  → 失败重试3次仍失败通知管理员
  → 恢复：快速(最近成功点) / 定点(选历史点，二次确认)
```

## 5. 关键技术方案

### 5.1 敏感数据脱敏
- **存储**：手机号/邮箱等敏感字段入库前脱敏（如 `138****1234`），或加密存储
- **展示**：统一在 Service 出参层处理，仅授权角色可见完整值
- **禁止**：不存储身份证号、银行卡号（表结构、校验层双保险）

### 5.2 关键数据加密
- 财务金额等关键字段加密存储，密钥定期轮换（Spring 提供加解密抽象，密钥走环境变量）

### 5.3 权限模型（RBAC）
```
用户 → 用户-角色 → 角色 → 角色-权限 → 权限(模块+操作)
```
- 4 类默认角色 + 自定义角色
- 权限点按「模块+操作」建模，前端菜单/按钮级 + 后端接口级双重校验

### 5.4 RAG 智能助手
```
文档上传 → 解析 → 文本分块 → Embedding → 向量库
提问 → 向量检索 TopK → 拼接上下文 → LLM 生成回答
```
- 降级策略：LLM 超时/不可用 → 返回知识库原始检索结果 + 台账摘要
- 对 AI 输出增加业务规则校验

### 5.5 定时任务
- 资质到期提醒（提前 15 天）、自动备份、未处理预警重复提醒，统一用 Spring `@Scheduled` / Quartz 管理
