## 3. 设计规范（UI 设计师 P6 参考）

- **配色**：主色 `#1f3a5f`（深蓝，已用于侧边栏）；功能色 success `#67c23a` / warning `#e6a23c` / danger `#f56c6c`
- **表单**：标签右对齐、必填 `*` 标识、校验错误字段红色边框 + 下方原因
- **表格**：敏感字段统一脱敏展示；操作列固定右侧
- **交互**：删除等敏感操作二次确认弹窗；越权弹窗统一文案「无此操作权限，请联系管理员」
- **响应式**：桌面优先，`<768px` 时侧边栏折叠为抽屉（H5 适配）
