# 测试资产

本目录存放《07·测试过程记录》对应的测试数据文件，均为离线可打开的 Excel。

| 文件 | 内容 | 规模 |
|------|------|------|
| `需求拆解与用例框架.xlsx` | Sheet1 需求拆解（模块/功能点/验收标准/用例编号）；Sheet2 用例库（完整字段）；Sheet3 用例统计 | 28 个功能点、312 条用例 |
| `缺陷台账.xlsx` | 缺陷明细（编号/模块/严重程度/状态/用例场景/复现步骤/预期结果/实际结果）与按模块统计 | 41 条，严重 7 / 一般 23 / 轻微 11 |
| `回归执行记录.xlsx` | Sheet1 按测试类型的执行汇总；Sheet2 312 条执行明细 | 通过 298 / 失败 8 / 阻塞 6 |

## 使用说明

- 用例编号规则：`TC-<模块>-<功能点>-<序号>`，如 `TC-M5-01-003`。
- 缺陷编号规则：`BUG-<阶段>-<序号>`，S2 为核心功能开发阶段、S3 为测试及部署阶段。
- 汇总数据与 `07-测试过程记录.md` 中的表格一一对应，可用于交叉核对。

## 维护约定

- 新增或修改用例后，需同步更新「用例统计」页与 `07-测试过程记录.md` 第 3 节。
- 缺陷状态变更需保留原编号，不重新编号。
